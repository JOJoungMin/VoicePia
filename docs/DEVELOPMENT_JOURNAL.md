## 2026-06-15 — 경쟁·유사 서비스 자료조사 (노벨라 벤치마크)

### 질문
노벨라와 같은 웹/앱 집필 도구를 이용자 많은 순으로 소개.

### 조사 결론 (요약)
공개된 **정확한 MAU**는 대부분 비공개. 아래는 공개 지표(다운로드·가입자·마케팅 수치)와 시장 지위를 종합한 **대략적 순위**.

| 순위 | 서비스 | 공개 규모 지표 | 노벨라 유사점 | VoicePia 차별화 여지 |
|------|--------|----------------|---------------|----------------------|
| 1 | Scrivener | 비공개 (2007~ 업계 표준) | 장편 집필·플롯·캐릭터 바인더 | 실시간 공동 집필 없음, 학습곡선 높음 |
| 2 | Campfire Write | 32만+ 작가 (공식 마케팅) | 월드빌딩·플롯·캐릭터 17모듈 | 실시간 동시 편집 약함, AI 없음 |
| 3 | 뮤블 (Muvel) | 10만~16만+ 다운로드 | 한국 웹소설, 플롯 캔버스·위키·에피소드 | 실시간 공동 집필 미약 |
| 4 | LivingWriter | 구독자 22~25년 180%↑ (리포트) | 클라우드·AI·협업·크로스디바이스 | 캐릭터 보이스 없음 |
| 5 | Dabble Writer | 9,500+ 작가 (공식) | Plot Grid(플롯 보드), 클라우드 협업 | 한국어·웹소설 특화 약함 |
| 6 | 노벨라 (벤치마크) | 비공개 | 플롯·인물·원고·AI·Win/Mac 동기화 | **실시간 공동 집필**은 아직 핵심 아님 |
| 7 | 타입탁 (Typetak) | 비공개 | 국내 AI 집필, 관계도·플롯·캐릭터 | AI 텍스트 중심, 보이스·실시간 협업 없음 |

**실시간 공동 집필에 가까운 신규 도구** (규모는 작지만 기술 참고 가치 높음): Tart (Yjs CRDT), Plotiar, Typewriter.digital, PubliWrite(3,000+ 작가).

## 2026-06-15 — 대화 맥락 보존 요청 & 기술 스택 1안 정리

### 요청 사항
- 집과 회사에서 다른 컴퓨터로 작업하므로, Cursor와의 대화 맥락이 끊기는 것이 아쉬움.
- **특정 파일**에 토의·진행 내역을 질문이 오갈 때마다 정리해 저장하기를 원함.
- → 이 파일(`docs/DEVELOPMENT_JOURNAL.md`)을 그 용도로 생성함.

### 서비스 개요 (목표)
**실시간 공동 집필 + AI 캐릭터 보이스 + 플롯 보드** 서비스.

핵심 요구사항 3가지:
1. **실시간 동기화** — 구글 독스처럼 여러 명이 동시에 써도 텍스트가 꼬이지 않아야 함 (WebSocket, 고속 데이터 처리).
2. **크로스 플랫폼 데스크탑** — Windows / Mac을 하나의 코드베이스로 지원.
3. **생산성과 친숙함** — 개발자(조민)가 가장 빠르고 완성도 높게 빌드할 수 있는 스택.

### 기술 스택 결정 (1안 — 가장 추천)

| 영역 | 선택 |
|------|------|
| 백엔드 (API & 실시간) | **C# ASP.NET Core + SignalR** (WebSocket 양방향 통신) |
| 프론트 & 데스크탑 | **Blazor Hybrid** (MAUI / Electron.NET / WebView2) |
| 언어 통일 | **C# (.NET)** — 백엔드·데스크탑·DI·최신 문법(Primary Constructor, `required` 등) 일관 적용 |

**1안을 추천하는 이유**
- 기존 .NET Core 마이그레이션·백엔드 아키텍처 역량을 그대로 활용 가능.
- SignalR이 Socket.io 대비 .NET 생태계에서 안정적·고성능 실시간 통신 제공.
- Blazor Hybrid로 HTML/CSS UI + C# 로직, Win/Mac 단일 코드베이스.
- Node.js·Python 등 새 스택 학습 비용 없이 프로덕션급 앱을 빠르게 출시 가능.

**2안** (이전 대화에서 언급됐을 수 있음): 아직 이 일지에 상세 기록 전 — 필요 시 다음 항목에 보완.

### 현재 저장소 구현 상태 (스냅샷)

이미 **1안 방향**으로 프로젝트 골격이 잡혀 있음:

```
VoicePia/
├── src/
│   ├── Voicepia.Api/          # ASP.NET Core API + SignalR Hub
│   ├── Voicepia.App/          # .NET MAUI Blazor Hybrid (Win/Mac/Android/iOS)
│   ├── Voicepia.Core/         # 도메인 모델
│   ├── Voicepia.Infrastructure/
│   └── Voicepia.Shared/       # Hub DTO (예: DocumentPresence)
```

**이미 구현된 것**
- `DocumentHub` — 문서별 그룹 참가/퇴장, `BroadcastEdit(byte[] update)` 로 편집 브로드캐스트
- `DocumentHubService` — MAUI 앱에서 Hub 연결·`JoinDocument` 호출
- `Document` 엔티티 — Id, ProjectId, Title, CreatedAt, UpdatedAt

**아직 없는 것 (예상)**
- CRDT/OT 기반 실제 텍스트 병합 로직 (Yjs, 자체 OT 등)
- AI 캐릭터 보이스 연동
- 플롯 보드 UI·데이터 모델
- 인증·프로젝트/문서 CRUD API 완성
- 프로덕션 배포·동기화 인프라
