# VoicePia 프로젝트 전제 (Project Context)

> **이 파일의 역할**: 프로젝트의 고정 전제. 바뀌지 않는 방향·규칙·학습 로드맵을 담습니다.  
> **일지와의 차이**: 날짜별 기록은 `docs/DEVELOPMENT_JOURNAL.md`, 여기는 "헌법".  
> **갱신 규칙**: 방향이 바뀔 때만 수정. 일상적인 진행은 일지에 기록.

---

## 1. 한 줄 정의

**실시간 공동 집필 + AI 캐릭터 보이스 + 플롯 보드**를 지원하는 **Windows / Mac 데스크탑 앱**.

경쟁 서비스(노벨라, Scrivener, 뮤블 등) 대비 차별점은 **다인 동시 편집이 텍스트를 꼬이지 않게 동작하는 것**과 **캐릭터별 AI 보이스**입니다.

---

## 2. 만들려는 것 (기능 단위)

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| **공동 집필 에디터** | 여러 명이 같은 원고를 동시에 편집, 충돌 없이 동기화 | 🔴 최우선 |
| **프로젝트·문서 관리** | 작품 단위 프로젝트, 챕터/원고 목록, 저장·불러오기 | 🔴 |
| **플롯 보드** | 줄거리·씬·관계를 시각적으로 배치·연결 | 🟡 |
| **캐릭터 관리** | 인물 설정, 관계, 대사 맥락 | 🟡 |
| **AI 캐릭터 보이스** | 캐릭터별 TTS로 대사 읽어 주기 | 🟡 |
| **인증·동기화** | 로그인, 클라우드에 원고·설정 저장 | 🔴 |

## 3. 기술 전제 (바꾸려면 일지에 결정 기록 후 수정)

| 영역 | 선택 | 이유 |
|------|------|------|
| 언어 | **C# / .NET** | 개발자 역량·생산성 |
| API·실시간 | **ASP.NET Core + SignalR** | WebSocket 양방향, .NET 생태계 |
| 데스크탑 | **.NET MAUI Blazor Hybrid** | Win/Mac 단일 코드베이스 |
| DB | **기존 배포 DB** (종류: 미정) | Docker 없이 시작 |
| 실시간 편집 병합 | **CRDT (Yjs 예정)** | SignalR만으로는 동시 편집 충돌 해결 불가 |
| 캐시·Redis | **초기 생략** | 단일 Api 서버로 시작 |

### 아키텍처 원칙

```
[Voicepia.App] ──HTTP/SignalR──▶ [Voicepia.Api] ──▶ [배포 DB]
```

- **App은 DB에 직접 연결하지 않음** — 항상 Api 경유
- **Core**: UI·DB 무관한 도메인 모델
- **Infrastructure**: EF Core, TTS 등 외부 연동
- **Shared**: Api ↔ App 공유 DTO

### 하지 않을 것 (명시적 요청 전)

- Docker Desktop 도입
- Electron / Node 백엔드로 스택 변경
- `appsettings`·Git에 비밀번호·연결 문자열 커밋

## 4. 현재 구현 상태 (2026-06-17 기준)

**완료**
- 솔루션 스캐폴딩 (Api, App, Core, Infrastructure, Shared)
- `DocumentHub` — 문서 방 입장/퇴장, 편집 바이트 브로드캐스트 뼈대

**미구현**
- DB 연결·EF Core·마이그레이션
- 인증 (JWT 등)
- 프로젝트/문서 CRUD API
- 실제 에디터 UI + Yjs 연동
- 플롯 보드, AI 보이스

## 6. AI(Cursor)에게 기대하는 역할

**해 줄 것**
- 스캐폴딩, 보일러플레이트, 에러 메시지 해석
- 개념 설명 (명령어·아키텍처·왜 이렇게 하는지)
- 코드 리뷰, 리팩터 제안 (요청 시)
- `DEVELOPMENT_JOURNAL.md`에 결정 사항 정리 제안

**하지 말 것**
- 사용자 동의 없이 대규모 구현을 한 번에 진행
- 기술 스택·아키텍처 원칙을 임의로 변경
- 학습 단계를 건너뛰고 "완성본만" 던지기

**요청 예시 (좋은 방식)**
- "1-2 EF Core 붙이는 걸 같이 하자. DbContext는 네가 틀만 잡고, 마이그레이션은 내가 실행할게"
- "SignalR Hub가 어떻게 동작하는지 `DocumentHub.cs` 기준으로 설명해줘"
- "이 에러 뭐야?" + 터미널 출력 붙이기
