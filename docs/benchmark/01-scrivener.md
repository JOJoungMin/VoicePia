> **벤치마크 순위**: 이용 규모 추정 1위 (장편 소설 집필 도구 카테고리)

> **공식 사이트**: https://www.literatureandlatte.com/scrivener/overview

## 한 줄 요약

2007년 출시 이후 **장편 소설·시나리오 집필의 사실상 표준** 데스크탑 도구. 구조화(바인더·코르크보드·아웃라이너)와 보내기(Compile)에 강하지만, **실시간 공동 집필·네이티브 클라우드·AI**는 거의 없음 — VoicePia가 차별화할 여지가 큰 영역.

## 핵심 기능

### 1. 바인더 (Binder) — 프로젝트 구조

- 링바인더 메타포: 원고·메모·리서치를 **하나의 프로젝트(.scriv)** 안에 계층 구조로 관리
- 챕터·씬·단락을 **임의 크기**로 분할, 드래그 앤 드롭으로 순서 변경
- **Scrivenings 모드**: 분할된 섹션을 하나의 연속 문서처럼 편집

### 2. 코르크보드 (Corkboard) — 플롯 보드에 해당

- 각 섹션에 **가상 인덱스 카드** + 시놉시스(synopsis) 부착
- 카드 이동 = **원고 구조 재배치** (플롯 보드와 원고가 연동)
- 노벨라·VoicePia의 **플롯 보드**와 가장 유사한 개념

### 3. 아웃라이너 (Outliner)

- 폴더·하위 폴더, 시놉시스, 단어 수, 메타데이터를 테이블 뷰로 관리
- 코르크보드와 동일 데이터의 **다른 시각화**

### 4. 캐릭터·설정 관리

- **캐릭터/장소 시트 템플릿** 제공 (커스텀 템플릿·아이콘 가능)
- 별도 "캐릭터 DB"라기보다 **프로젝트 내 문서/폴더**로 관리
- 노벨라·뮤블의 전용 캐릭터 UI보다 **유연하지만 진입 장벽 높음**

### 5. 리서치 통합

- PDF, 이미지, 웹 페이지, 오디오 등을 프로젝트에 임베드
- **스플릿 뷰**: 원고 옆에 리서치 자료 표시
- 인터뷰 **오디오 전사** 기능

### 6. 집필 환경

- 포커스/집중 모드, 작성 목표·진행률, 작성 히스토리
- 스타일 시스템 (블록 인용·제목 등 일괄 서식)
- 시나리오 모드 (Final Draft 연동·보내기)

### 7. Compile (보내기)

- EPUB, Kindle, PDF, DOCX, RTF, Final Draft, LaTeX(MultiMarkdown/Pandoc) 등
- 출판·투고용 서식을 **프로젝트별 Compile 프리셋**으로 관리
- **학습 곡선이 가장 가파른 기능** 중 하나 (사용자 리뷰 공통)

### 8. 스냅샷 (Snapshots)

- 섹션별 버전 스냅샷 저장·비교
- 노벨라 "버전 기록"과 유사, 단 **자동 클라우드 버전**은 아님

## 협업 · 동기화 · 클라우드

| 기능 | Scrivener | 노벨라 | VoicePia 목표 |
|------|-----------|--------|---------------|
| 실시간 다인 동시 편집 | ❌ 없음 | ❌ (링크 공유·첨삭 수준) | ✅ 핵심 |
| 네이티브 클라우드 | ❌ 없음 | ✅ | ✅ |
| 기기 간 동기화 | Dropbox 등 **서드파티** | 자동 동기화 | 자동 동기화 |
| 동시 오픈 제한 | ⚠️ **한 기기에서만** 프로젝트 열기 | 해당 없음 | 동시 편집 허용 |

**공식 동기화 가이드 (Dropbox 기준)**
- 동일 프로젝트를 **두 기기에서 동시에 열면 안 됨**
- 클라우드 동기화 **완료 후** 열고/닫을 것
- "스마트 동기화"(로컬 미보관) 사용 시 프로젝트 손상 위험
- 공동 집필 시: **Import & Merge**로 수동 병합, 또는 Word/PDF로 보내 외부 피드백

> **결론**: Scrivener 아키텍처는 **1인 로컬 프로젝트** 전제. VoicePia의 SignalR + CRDT/OT 방향과 정반대 설계 철학.

## VoicePia 관점 — 배울 점 vs 넘어설 점

### 배울 점 (UX·기능)

1. **구조와 원고의 양방향 연동** — 코르크보드에서 플롯을 움직이면 원고 순서가 바뀜
2. **Scrivenings 모드** — 씬 단위 편집 ↔ 전체 원고 뷰 전환
3. **스플릿 뷰** — 원고 + 설정/리서치 동시 참조 (노벨라 스플릿뷰와 동일 니즈)
4. **Compile** — 다양한 출판 포맷 일괄보내기 (EPUB 등)
5. **스냅샷** — 버전 비교·복원

### 넘어설 점 (차별화)

1. **실시간 공동 집필** — Scrivener의 구조적 공백
2. **네이티브 클라우드** — Dropbox 수동 동기화 불필요
3. **한국 웹소설 워크플로** — 회차·연재·글자 수(공백/부호 제외) 등
4. **AI 캐릭터 보이스** — Scrivener·노벨라 모두 미제공
5. **진입 장벽** — Scrivener는 "747 조종석" 비유가 반복됨 → VoicePia는 단순함 유지

## 기술 스택 (추정)

| 영역 | 내용 |
|------|------|

## 사용자 평가 요약

**장점 (리뷰 공통)**
- 장편 원고 구조 관리 최강
- 일회 구매·구독 없음
- Win/Mac 프로젝트 호환
- 리서치·시나리오·비문학까지 폭넓음

**단점 (리뷰 공통)**
- 학습 곡선 가파름, Compile 혼란
- 실시간 협업 없음
- Word Track Changes 미지원 → 편집자 워크플로와 단절
- 클라우드 동기화 "구식" (충돌 파일 위험)
- UI 노후감 (10년+ 코드베이스, 전면 재작성 계획 없다는 외부 평가)
